Política de Privacidad de TaskFlow

Actualización de información pública: 20 de noviembre de 2026. Esta publicación reproduce los apartados pertinentes de las políticas existentes dentro de TaskFlow y añade información específica sobre la integración opcional de Gmail.

Conexión opcional con Google Gmail — V175

TaskFlow permite que el usuario conecte voluntariamente una cuenta de Gmail mediante OAuth 2.0 para organizar tareas académicas o laborales. La autorización solicita exclusivamente el permiso gmail.readonly para consultar mensajes del buzón de entrada y extraer, cuando se identifiquen con suficiente certeza, curso o categoría, asunto de la tarea y fecha y hora de entrega. El usuario debe comprobar que las fechas detectadas correspondan a las instrucciones originales.

Información consultada y almacenada

Con la autorización correspondiente, el servicio accede al contenido y metadatos de los mensajes recibidos después de la conexión. Procesa su contenido para determinar si hay una actividad relevante, sin conservar una copia íntegra del cuerpo del correo como parte del registro de tareas. Puede guardar la dirección vinculada, identificadores de mensajes, categoría principal, curso, título, información sobre el vencimiento, estado de cumplimiento y datos mínimos de sincronización. Para mantener la conexión, el servidor almacena de forma cifrada el token de actualización de OAuth.

Finalidad y servicios técnicos

Esta información se utiliza para detectar y administrar tareas, sincronizar categorías y registrar fechas de cumplimiento. Se procesa mediante infraestructura de Google y Supabase; Firebase se utiliza para identificar a la cuenta de TaskFlow. El contenido de Gmail no se utiliza para crear perfiles publicitarios, mostrar anuncios personalizados, comercializar datos ni entrenar modelos de inteligencia artificial. No se autoriza el envío, modificación ni eliminación de mensajes de Gmail.

Acceso, conservación y desconexión

El acceso depende del consentimiento del usuario. Puede desconectar la cuenta en TaskFlow; la desconexión desactiva nuevas consultas y elimina el token guardado para esa conexión. Las tareas, cursos y registros derivados que ya se hayan generado pueden permanecer asociados a su cuenta hasta que se eliminen mediante las funciones disponibles o se solicite su eliminación a soporte. El sistema no garantiza detectar correctamente todos los correos o fechas; los mensajes ambiguos pueden requerir revisión.

Control y contacto

Para preguntas sobre la información almacenada, solicitar correcciones o pedir la eliminación de datos asociados al correo institucional, escribe a novaprime.gt@gmail.com.

El uso de datos obtenidos mediante Google APIs se limita a proporcionar y mejorar las funciones visibles de organización solicitadas por el usuario y está sujeto a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de uso limitado.

2. Política de privacidad

TaskFlow está pensado para conservar la información principal del usuario en su propio dispositivo. No requiere una cuenta personal obligatoria para utilizar las funciones principales descritas en esta versión.

Información que puede registrar el usuario
  • Tareas, títulos, descripciones, prioridades, fechas y estados de cumplimiento.
  • Hábitos, categorías, cursos, frecuencia y registros de cumplimiento.
  • Misiones obligatorias y su estado diario.
  • Puntos, EXP, niveles, rangos, rachas, penalizaciones y recompensas.
  • Estado de la misión económica diaria de Q100 y progreso del ciclo de la tienda.
  • Preferencias y otros datos necesarios para conservar el progreso personal.
  • Si creas una cuenta: edad declarada por ti y autorización voluntaria para segmentación publicitaria. La edad no se verifica mediante documentos.

No deben registrarse contraseñas bancarias, números completos de tarjeta, claves privadas, PIN, credenciales financieras ni documentos de identidad en campos de notas o textos personales.

3. Datos guardados en el dispositivo

TaskFlow guarda información de progreso en el dispositivo para que las tareas, hábitos, rangos, recompensas y demás avances permanezcan disponibles entre usos.

  • Los datos pueden perderse si se eliminan los datos de TaskFlow, se restaura el dispositivo, se reinstala la aplicación o se cambia de dispositivo sin una copia de respaldo.
  • TaskFlow relaciona los anuncios con el tema general de la sección abierta. Las tareas, notas, hábitos, datos financieros y contenido personal se reservan para las funciones de TaskFlow.
  • El usuario debe mantener copias de respaldo cuando la información acumulada sea importante para él.

4. Notificaciones, compartir y permisos

TaskFlow puede solicitar permisos del dispositivo para funciones como notificaciones o compartir información cuando el usuario decide utilizarlas.

  • El usuario puede aceptar o rechazar permisos disponibles desde la configuración de su dispositivo.
  • La entrega exacta de una notificación puede variar según las restricciones de energía, permisos o funcionamiento del dispositivo.
  • Al compartir contenido hacia otra aplicación o servicio, el tratamiento posterior de esa información depende del destino elegido por el usuario.

Ubicación del dispositivo. Con tu permiso, TaskFlow usa la ubicación en tu dispositivo exclusivamente para ajustar la zona horaria del reloj del sistema. Las coordenadas se quedan en el dispositivo y TaskFlow no las envía ni las comparte con terceros. Puedes usar la zona horaria del dispositivo si prefieres omitir el permiso.

11. Seguridad

La información personal de TaskFlow debe considerarse privada y protegerse mediante las medidas de seguridad disponibles en el dispositivo.

  • No introducir secretos, contraseñas, PIN, tarjetas, información médica detallada ni otra información altamente sensible.
  • Mantener activo el bloqueo de pantalla y las medidas de seguridad del dispositivo.
  • Utilizar únicamente copias de TaskFlow obtenidas de una fuente de confianza.

12. Pérdida de datos, respaldo y restauración

La información guardada puede perderse por eliminación accidental, daño del dispositivo, restauración, cambio de dispositivo o fallas imprevistas.

  • Cuando esté disponible una función de respaldo, se recomienda realizar copias periódicas.
  • No se garantiza la recuperación de información eliminada si no existe una copia previa.
  • Antes de realizar cambios importantes, el usuario debe proteger la información que desee conservar.

13. Servicios externos

Algunas acciones iniciadas por el usuario, como compartir contenido, abrir enlaces o utilizar servicios del dispositivo, pueden involucrar servicios externos a TaskFlow.

Una vez que el usuario sale de TaskFlow o envía información a otro servicio, se aplican las condiciones y políticas de ese destino. TaskFlow no controla el tratamiento realizado por servicios externos.

14. Menores de edad

Si un menor utiliza TaskFlow, su padre, madre o responsable debe supervisar especialmente las metas físicas, económicas, recompensas, compras y la información que se registre.

15. Control, corrección y eliminación de datos

El usuario conserva control sobre la información que registra en TaskFlow y puede modificar o eliminar datos mediante las funciones disponibles. TaskFlow no elimina automáticamente tareas, hábitos, categorías o cursos creados por el usuario únicamente por antigüedad o cantidad.

  • Corregir información: editar tareas, hábitos, categorías u otros datos cuando la función esté disponible.
  • Eliminar información: borrar elementos individuales o eliminar los datos guardados de TaskFlow.
  • Retirar permisos: utilizar la configuración del dispositivo cuando corresponda.
  • Antes de eliminar información de forma general, realizar un respaldo si desea conservar el historial.

20. Publicidad en TaskFlow

En el plan gratuito, TaskFlow puede mostrar anuncios relacionados con la sección abierta, como anuncios deportivos en una rutina de ejercicio. Al crear una cuenta se solicita una edad declarada (no verificada documentalmente). Si eres mayor de 18 años y autorizas expresamente la personalización, los anuncios también podrán seleccionarse según esa edad y categorías de interés aprendidas únicamente de clics publicitarios confirmados.

El perfil de intereses se almacena de forma privada en categorías acumuladas, sin guardar un historial adicional de anuncios o sitios visitados. Las categorías sin actividad reciente dejan de utilizarse después de 90 días. En tu perfil puedes cambiar el permiso o eliminar los intereses aprendidos. Los menores no participan en este aprendizaje publicitario.

La ubicación utilizada para el reloj permanece en tu dispositivo y no se utiliza para publicidad. Por separado, si activas la opción de zona publicitaria, TaskFlow podrá utilizar el país, departamento y municipio que declares voluntariamente para seleccionar anuncios. Puedes retirar esta autorización desde Privacidad publicitaria en el menú.

No se utilizan para perfilado publicitario el contenido de tus hábitos, tareas, presupuesto ni la ubicación del reloj.

Los anunciantes reciben métricas agregadas de su campaña. Si tienes la membresía Sin anuncios activa, TaskFlow omite la publicidad.
