TaskFlow

TaskFlow es una aplicación para organizar tareas, hábitos, categorías, cursos, rutinas y progreso personal. Permite consultar actividades, registrar su cumplimiento y gestionar fechas.

Organización académica y laboral

La función de correo institucional, cuando el usuario decide activarla y autorizar el acceso, permite conectar Gmail para detectar posibles tareas en mensajes recibidos, identificar cursos o categorías y reconocer fechas de entrega. Las tareas institucionales se muestran entre las activas dos días antes del vencimiento. No se registra una falta antes de la fecha límite correspondiente.

El acceso al correo es opcional y se utiliza únicamente para esta funcionalidad. La aplicación no necesita permisos para enviar o eliminar mensajes.
